# Should the Digital Euro Bear Interest?

Programmable holding costs, the lower bound, and why the only usable form is demurrage.
A 20-minute talk with 10 minutes of Q&A, written as the price-side companion to a talk on digital-euro holding limits.

## Contents

| Path | What |
|---|---|
| `slides/slides.tex`, `slides/slides.pdf` | Beamer deck (16 main slides + 5 backup) |
| `script/script.tex`, `script/script.pdf` | A4 speaker script: slide on top; talking points, terms and Q&A below |
| `model/expiry_vs_demurrage.py` | Model comparing hard expiry with continuous demurrage; prints all tables |
| `figures/` | Figure generated by the model |
| `notes/01_outline_and_math.md` | Storyline, model, results |
| `notes/02_literature.md` | Literature review and where the increment lies |

## Build

```bash
pip install numpy scipy matplotlib
python3 model/expiry_vs_demurrage.py      # tables + figures/expiry_vs_demurrage.{pdf,png}
cd slides && pdflatex slides.tex && pdflatex slides.tex
cd ../script && pdflatex script.tex && pdflatex script.tex   # needs slides/slides.pdf
```

Requires TeX Live with `beamer`, `eurosym`, `enumitem`, `fancyhdr`.
