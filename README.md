# Use It or Lose It?

Programmable money and the digital euro's interest rate. A 20-minute talk with 10 minutes of Q&A.

## Contents

| Path | What |
|---|---|
| `slides/slides.tex`, `slides/slides.pdf` | Beamer deck (10 slides + 4 backup); each title is one sentence of the argument |
| `slides/beamerthemequiet.sty` | Minimal beamer theme (Palatino, one accent colour) |
| `script/script.tex`, `script/script.pdf` | A4 speaker script: slide on top; talking points, terms and Q&A below |
| `model/expiry_vs_demurrage.py` | Expiry vs continuous decay; prints tables, exports `figures/expiry_paths.csv` |
| `model/hybrid_design.py` | Price/quantity hybrid calibrated to euro-area data: free tier, Pigouvian rate, cap |
| `figures/` | Figure generated by the model |
| `notes/01_outline_and_math.md` | Storyline, model, results |
| `notes/02_literature.md` | Literature review |
| `notes/03_hybrid_derivation.md` | Derivation and calibration of the hybrid design |
| `notes/04_layout.md` | Slide-by-slide layout choices |

## Build

```bash
pip install numpy scipy matplotlib
python3 model/expiry_vs_demurrage.py      # tables + figures (CSV used by the deck)
python3 model/hybrid_design.py            # calibration of the hybrid design
cd slides && pdflatex slides.tex && pdflatex slides.tex
cd ../script && pdflatex script.tex && pdflatex script.tex   # needs slides/slides.pdf
```

Requires TeX Live with `beamer`, `pgfplots`, `mathpazo`, `eurosym`, `colortbl`, `enumitem`, `fancyhdr`.
